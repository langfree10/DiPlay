# DiPlay 伊兰特 1.0.0

发布日期：2026-10-23。第一个正式版本，基于上游 DiPlay 0.2.21 和实车验证通过的 elantra-test12。

## 已实车验证

- 蓝牙音乐播放、方向盘音量及上一首／下一首；修复单按切两首及吞键。
- USB 导航播报，可选兼容、清晰优先、48 kHz PCM。晚间日志的 77 次导航音轨初始化均为 48 kHz 双声道 LPCM。
- Siri 回复可听到，结束后恢复蓝牙音源；4 次恢复均获得车机原厂音频焦点确认。
- 直角全屏及 0 mA 充电电流请求。0 mA 是协议请求，不代表切断 USB 5V。

## 安装与使用

本地交付文件：`DiPlay-Elantra-1.0.0.apk`。显示名“DiPlay 伊兰特”，版本代码 52，保持 `com.shihab.diplay.hudtest` 与原签名，可直接覆盖 test12，保留设置。使用关闭调试的 release 构建，不包含测试专用组件。本次没有变更连接、音频或按键算法。

继续使用原有 USB 线及蓝牙配对。播放音乐时原车 MODE 选择“蓝牙音频”；“我的音乐＋静音文件”只用于屏蔽收音机。音质设置在“高级 → 视频与音频 → USB 提示音质”，修改后重新连接。48 kHz 对导航生效，Siri 可使用 24／48 kHz。

适用验证范围：2021 款第七代伊兰特、Humax BHCN-T3103C、Android 9 / API 28、后加装 360、无 Wi-Fi 模块。其他车型、固件、无线盒子和各类 USB 重连时序不视为已验证。
