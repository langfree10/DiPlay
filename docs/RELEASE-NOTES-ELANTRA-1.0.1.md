# DiPlay 伊兰特 1.0.1

发布日期：2026-10-23。在 1.0.0 基础上将已验证的 48 kHz PCM 设为伊兰特默认导航音质。

- 新安装或未保存过音质选择的匹配伊兰特车机，默认选择 48 kHz PCM。
- 继续提供“兼容／清晰优先／48 kHz PCM”三个档位；已有手动选择保持不变，旧版已保存的兼容／清晰优先同样保留。
- 其他车型默认值不变，Siri、音乐、电话和麦克风格式不变；切换音质后重新连接 CarPlay 生效。
- 版本代码 53，包名与签名保持不变，可覆盖 1.0.0 或 test12 并保留设置。实车功能验证仍以 test12 及 1.0.0 发布记录为依据。

音质设置：设置 → 高级 → 视频与音频 → USB 提示音质。

检查结果见[验证记录](ELANTRA_AUDIO_TEST.md)，前一版说明见[1.0.0](RELEASE-NOTES-ELANTRA-1.0.0.md)。安装包本地交付，认证和签名资料不进入 Git。

本地检查：3194 项通过、1 项原有跳过、0 失败；三项已知本机网络用例按车主要求排除。完整 debug 检查及正式 release 构建、lint 和 APK 校验完成。
