# 伊兰特适配与验证记录

适配基线：DiPlay 0.2.21，`6d3b8a8ce927cb4b115b8c3881f17619433e93b1`。当前正式版本：`1.0.0`，实车验证基线：`0.2.21-elantra-test12`。本记录更新于 2026-10-23。

## 实车范围

2021 款第七代伊兰特，后加装 360，Humax `BHCN-T3103C` / Android 9 / API 28，无 Wi-Fi 模块。有线连接 iPhone，原车 MODE 选择“蓝牙音频”播放音乐。

“我的音乐＋静音文件”只用于屏蔽收音机，不能据此把实际音乐音源强制设成“我的音乐”。保留车主原有音频传输设置；源名称、蓝牙连接状态和 USB 音频数据应分别观察。
