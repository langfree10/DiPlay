# 伊兰特适配与验证记录

适配基线：DiPlay 0.2.21，`6d3b8a8ce927cb4b115b8c3881f17619433e93b1`。当前源码版本：`0.2.21-elantra-test12`。本记录更新于 2026-10-23。

## 实车范围

2021 款第七代伊兰特，后加装 360，Humax `BHCN-T3103C` / Android 9 / API 28，无 Wi-Fi 模块。有线连接 iPhone，原车 MODE 选择“蓝牙音频”播放音乐。

“我的音乐＋静音文件”只用于屏蔽收音机，不能据此把实际音乐音源强制设成“我的音乐”。保留车主原有音频传输设置；源名称、蓝牙连接状态和 USB 音频数据应分别观察。

去重的 120 ms 是基于已观察到的镜像事件延迟选择的有限窗口，不是物理按键唯一标识；跨入口的独立快速操作可能被合并，超过窗口的镜像仍可能重复。成功写入、播放头前进或焦点获批也不能证明扬声器实际出声。

## 后续实车检查

停车后沿用当前正常的蓝牙与音频设置：

1. 单按下一首／上一首应各切一首，连续按两次应切两首。
2. test11/12 让 Siri 给出语音回答，确认能否听见，并确认结束后恢复蓝牙音源。
3. 在“高级 → 视频与音频 → USB 提示音质”选择 48 kHz PCM，重新连接后播放导航，确认实际显示本次连接的 48 kHz PCM。若无播报，改回清晰优先或兼容再重连。
4. 若 Siri 仍无声，导出报告查看助手输出的配置用途、非零样本数及峰值；只记录计数，不保存音频。

日志可通过“诊断 → 导出到 U 盘／文件夹”保存。公开反馈前去除个人资料；本仓库仅保留验证结论和合成测试数据，不提交车主原始日志、设备配对记录、运行私钥或固件包。
